## Risks

- **Nothing has ever run in CI.** The delivery has no `.git`, so `.github/workflows/*` is a promise,
  not evidence. Until a first green run exists on `main`, Article 7 is unenforced.
- **Phase 1 sits on top of the downloader that was broken last week.** The loaders for puzzles and
  TWIC do not exist yet, and `make data-sample` only prints its config. Building the data phase
  before the downloader is trustworthy would waste disk at GB scale and — worse — would produce shards
  that *look* verified.
- **Acceptance and authorship were the same agent** in session 0002. ADR-0003 flags this as a conflict
  of interest; an independent reproduction is the cheapest insurance.
- **Doc drift is chronic.** Ten claims in docs and docstrings did not match the code (a mock arena
  described as real games, a nightly job claiming 10k positions, YAML manifests that are JSON). None
  were lies; all were the natural sediment of a fast build. Article 5 needs the same reproduction
  standard applied to prose as to code.
