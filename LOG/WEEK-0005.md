the loss exploding (3.44 → 27.6, rising) at `lr=0.05` and decreasing at `lr<=0.01`. The v1 linear

## What the project's own gates caught

1. **A confounder in the eval set** (preflight): the main run (K=8) and the `no_history` ablation
   (K=0) were scored on **different** position sets, so a top-1 delta would have mixed the organ's
   effect with a change of eval set. Fixed with `window_history`; pinned by a mutation-verified test.
2. **A ref-update/dispatch race**: the first shot started on the wrong commit (`ff7e2813`). Caught
   by checking `head_sha` at dispatch, cancelled, and recorded as **VOID** in the append-only
   registry — a run on the wrong commit is not a result.
3. **A gap in the verdict rule**: a diverged (NaN) run falls through to INCONCLUSIVE, which reads as
   "interesting but not convincing" when the truth is "the model was destroyed". Recorded as a
   defect in the *rule*; the fix is a new pre-registration, not a moved threshold.
