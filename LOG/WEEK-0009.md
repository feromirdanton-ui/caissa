**Window:** sessions 0012–0013. **Question of the week:** *why does the v2 family diverge, and does

## What changed in the project's truth

1. **The v2 divergence is now attributed, not just observed.** Session-0012 established *that* v2
   diverges (val loss 3.3453 → 25.1846, grad norm 4.82 → 648). Session-0013's forensics established
   *where*: the **bilinear head explodes first, at step 3**, the encoder and mixer follow at step 4,
   and the geometry scalar never explodes. `max|logit|` runs 2.12 → 794.7 (peak 2806.69) — the logits
   are unbounded, which is the mechanism.
2. **A cause fix exists and is testable.** Cosine (unit-normalised) logits bound every logit by
   `scale × n_heads` however large the weights grow — the mechanism removed, not damped. Gradient
   clipping (F1) only damps the symptom. The F0–F4 factorial tests which is enough.
3. **The verdict rule was repaired.** Session-0012's machine printed `SUCCESS` on a run where every
   delta was negative — a McNemar polarity defect (`favours == "b"` is a v1 win, not a v2 win). Fixed
   and pinned by a mutation-control test. The 0012-3 verdict is frozen as **DEAD**, with the caveat
   that the duel was run against a non-converging contender.
4. **A finite blow-up is now a divergence.** `PlateauTracker` gained a DIVERGED status (final > 2×
   best), decided by ONE function shared with the run guard, with mutation control on both real 0012
   curves. Session-0012's run reported `PLATEAUED` on a curve that went 3.35 → 25.2; that can no
   longer be read as a result.
5. **The transport threshold earned its keep.** A fourth transcription incident (a dropped letter in
   a 5158 B workflow) was caught by the verify duty and fixed structurally — the file was shrunk
   below 2 KB rather than retyped. ADR-0012 now names GitHub Releases as the payload store.
