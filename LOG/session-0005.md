## Шаг 2 — загрузчики океана

Три источника Фазы 1, все с гарантиями `lichess_bulk` (`.part` + `Range`, атомарный rename,
sha256 **до** записи манифеста, громкий отказ на несертифицируемом теле — Article 14).

| Источник | Модуль | Особенность |
|---|---|---|
| Lichess puzzles | `src/caissa/acquisition/puzzles.py` | один потоковый проход: считает **все** строки и пишет образец + гистограмму рейтингов; перепроверка sha завершённого архива |
| TWIC | `src/caissa/acquisition/twic.py` | месяц **обнаруживается** по измеренному `Last-Modified`; якорь issue 1500 → 2023-08-08 измерен `HEAD`; пауза между запросами к публичному сайту (§6.6) |
| Lichess bulk (день) | `lichess_bulk.py` → `download_prefix` | образец-день = **голова** месячного архива (архив хронологичен), resumable, ограниченный `Range`, `remote_total` измеряется и записывается |

Оркестрация — `src/caissa/acquisition/sample.py`, одна команда: `make data-sample` =
`python scripts/run.py data-sample` (ADR-0005). Квота диска проверяется **до** старта,
свободное место печатается в начале и конце, `.part`-гигиена отражается в отчёте.

## Шаг 3 — раннер как приёмочная машина для данных

`.github/workflows/data-sample.yml` (`workflow_dispatch`): чистый клон → установка →
clone-guard → выкачка → сверка sha256 → **доказательство resume в ране** → QA-артефакт.

Доказательство resume — не словами: в ране файл-день обрезается до 50 %, загрузчик
перезапускается, и тест утверждает `resumed_from == half`, `fetched_bytes == prefix - half`,
`fetched_bytes < prefix` и **совпадение sha256** с полным префиксом. Артефакт `data-sample-qa`
несёт `qa-lite.json` и все манифесты; данные в git не попадают никогда (`data/**` по путям).

Clone-guard (`git ls-files -i -c --exclude-standard` + «грязный чекаут») уже стоит в `ci.yml`
с session-0003 и обобщён на пути; `data/**` игнорируется **по путям**, не по расширениям.

**URL-ы ранов:** _заполняются после прогона; отчёт без URL рана — не отчёт._

## Риски и открытые вопросы

1. **Префикс — усечённый поток.** У zstd-префикса нет корректного конца; QA читает до последнего
   целого блока и отбрасывает хвост. Это записано как ограничение (ADR-0006), а не выдаётся за
   разбор полного месяца. Целые архивы — дело Фазы 2.
2. **Якорь TWIC стареет.** Окно ±12 недель (расширяется один раз) делает дрейф самоисправляющимся,
   но очень старый месяц может потребовать явного якоря.
3. **Призрак в консольных скриптах.** Тест защищает импорт в pytest; `caissa-download` всё ещё
   разрешается через установленный entry point — README говорит об этом; общее лечение — venv
   на чекаут.
4. **Пуш через API, не git.** SSH-путь в этой среде без ключа; изменения вносятся GitHub API
   (tree → commit → ref). Следствие: локальная git-история не является авторитетом — таковым
   является репозиторий (ADR-0004).
